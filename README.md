## What I Build

I build practical tools for gaming communities: Discord automation, guild coordination systems, onboarding flows, admin dashboards, and voice tools made for real server activity.

My work is focused on clarity, reliability, and making community management easier for guild leaders, staff teams, and event organizers.

## Featured Work

### Shotcaller BOT / Saint Relayer

**Main project:** a Discord voice relay built for large-scale MMO guild coordination.

- Tested in **Throne and Liberty EU** by multiple guilds
- Relays one commander voice into multiple Discord voice channels
- Built for raid-leading, large fights, castle pushes, boonstone/riftstone content, and guild events
- Designed for guilds that need clear communication across multiple squads
- Permanently free and nonprofit

### Saint Builder

A Discord server builder for turning an existing server into an organized community from ready-made blueprints.

- Builds roles, categories, channels, permissions, embeds, and staff areas
- Supports structured community setup
- Built around Discord automation and clean admin workflows

### Saint Teams

Team organization tools for communities that need cleaner structure around groups, roles, and activity.
